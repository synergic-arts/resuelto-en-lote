DIVIDIR CSV

Parte un archivo enorme en trozos manejables para subirlo, importarlo o compartirlo sin hacerlo a mano.

El archivo no sale de tu dispositivo. La lectura, la división y la preparación de las descargas se realizan dentro de este navegador. No hay cuentas, subidas ni conexiones de red.

La aplicación entiende comas entrecomilladas, comillas dobles escapadas y saltos de línea dentro de una celda. Cada parte queda como un CSV independiente.
