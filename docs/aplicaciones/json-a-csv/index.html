JSON A CSV

Pasa datos de una API o aplicación a una tabla que puedas abrir en Excel.

Tus datos se quedan en tu dispositivo. El JSON se analiza y se convierte dentro del navegador. No hay cuentas, subidas, cookies ni conexiones a Internet.

Admite una lista de objetos, un objeto individual o un objeto que contenga una lista. Las listas dentro de cada registro se conservan como JSON en una celda.

Pega un JSON o selecciona un archivo.

Todavía no hay resultados.

Qué se conserva. Los nombres de campo y los valores se pasan a columnas. Los objetos anidados se pueden aplanar; las listas se guardan como JSON dentro de una celda. No se genera un libro XLSX con fórmulas o estilos.
Revisa las columnas y los valores antes de importarlos en Excel, Google Sheets o una base de datos.
