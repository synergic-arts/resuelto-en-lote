UNIR IMÁGENES

Junta capturas, recibos o fotos en una sola imagen lista para compartir.

Las imágenes se quedan en tu dispositivo. Se abren, se colocan y se exportan dentro de este navegador. No hay cuentas, subidas ni cambios en los archivos originales.

    Usa la disposición vertical para unir capturas de una conversación o un documento. Usa la horizontal para comparaciones de antes y después. Puedes subir o bajar cada imagen antes de crear la composición.

    Selecciona al menos 2 imágenes.

    Todavía no hay resultados.

    Imagen finalDescargar imagen
    La unión crea una imagen nueva. La aplicación no cose panoramas ni corrige perspectivas: coloca las imágenes en el orden elegido, con el tamaño y la separación indicados. Si el lienzo resultante es muy alto o ancho, reduce el lado máximo.
    Compatible con JPG, PNG y WebP en navegadores modernos. Revisa la composición antes de compartirla y conserva los originales si los necesitas.
