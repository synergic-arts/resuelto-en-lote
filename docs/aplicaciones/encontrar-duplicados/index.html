ENCUENTRA DUPLICADOS

Localiza copias exactas antes de mover o borrar nada.

Solo lectura. Los archivos se comparan dentro de tu navegador mediante tamaño y SHA-256. No se envían a Internet y la aplicación no borra ni mueve ningún archivo.

Se comprueba el contenido completo solo entre archivos con el mismo tamaño. Los duplicados visuales guardados con distinta calidad o formato no se consideran iguales.

Selecciona una carpeta o varios archivos.

    Máximo recomendado: 5.000 archivos y 1 GB por lote. Revisa las rutas y conserva una copia de seguridad antes de tomar decisiones.
