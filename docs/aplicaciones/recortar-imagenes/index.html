RECORTA EN LOTE

Adapta muchas imágenes al mismo formato para redes sociales, vídeos o catálogos.

Tus imágenes se quedan en tu dispositivo. El recorte se calcula y se exporta dentro de este navegador. No hay cuentas, subidas ni cambios en los originales.

La misma proporción y el mismo punto de referencia se aplican a todo el lote. El resultado conserva la resolución disponible del recorte y se guarda como una copia nueva.

Selecciona una o varias imágenes.

Todavía no hay resultados.

    El recorte por lotes usa el mismo encuadre para todas las imágenes. Si cada foto tiene el sujeto en un lugar diferente, revisa las miniaturas antes de compartirlas y usa el punto de referencia más adecuado.
    Compatible con JPG, PNG y WebP en navegadores modernos. La aplicación procesa hasta 30 imágenes por lote y ofrece una descarga independiente para cada una.
