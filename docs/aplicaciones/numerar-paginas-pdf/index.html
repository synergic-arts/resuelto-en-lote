NUMERA TU PDF

Añade una numeración clara a informes, contratos y documentos antes de compartirlos o imprimirlos.

Tu PDF se queda en tu dispositivo. La numeración se dibuja dentro de este navegador y se descarga como una copia nueva. No hay cuentas, subidas ni cambios en el archivo original.

La primera página numerada usa el número inicial que elijas. Si omites páginas, el recuento continúa desde ese número en la primera página que sí se numera.

La numeración se añade como texto visible. Si el PDF ya tiene números, pueden quedar duplicados. Revisa siempre la copia final y comprueba que la posición no tape contenido importante.
Compatible con PDF en navegadores modernos. La aplicación trabaja con un documento cada vez y recomienda no superar 100 MB para mantener una respuesta fluida.
