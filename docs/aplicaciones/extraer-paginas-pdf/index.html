EXTRAER PÁGINAS DE PDF

Elige las páginas que necesitas y crea un PDF nuevo sin enviar el original a ningún servidor.

El documento se queda en tu dispositivo. No hay cuentas, registro ni subidas. La lectura y la extracción se ejecutan en un proceso aislado del navegador.
Todavía no has seleccionado ningún documento.

Puedes usar páginas sueltas y rangos, por ejemplo: 1-3, 7, 10.

Selecciona un PDF para empezar.
Descargar PDF nuevo
Límites importantes. El documento debe poder abrirse sin contraseña. Las páginas se copian a un archivo nuevo; las firmas digitales, formularios, marcadores, adjuntos o elementos interactivos pueden no conservarse. Revisa el resultado antes de archivar el original.
Máximo recomendado: 250 MB por documento. Biblioteca incluida: pdf-lib 1.17.1, licencia MIT.
