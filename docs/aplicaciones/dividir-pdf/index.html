Separa un documento grande en partes manejables sin volver a subirlo a ningún sitio.

El PDF se queda en tu dispositivo. La división se hace dentro del navegador. No necesitas crear una cuenta ni enviar el documento a un servidor.

    Revisa los archivos antes de compartirlos. La aplicación copia las páginas a documentos nuevos. En PDF con formularios, marcadores, firmas o elementos interactivos, comprueba que cada parte conserva lo que necesitas.
    Compatible con navegadores modernos. Trabaja con un documento cada vez y recomienda no superar 100 MB para mantener una respuesta fluida.
