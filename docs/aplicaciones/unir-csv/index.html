UNE CSV

Junta varios archivos CSV aunque sus columnas lleguen en distinto orden.

Procesamiento local. Los archivos se leen y se combinan dentro de tu navegador. No se envían a Internet y los originales no se modifican.

La primera fila de cada archivo se usa como cabecera. Las columnas se alinean por nombre y las que falten quedan vacías.

Selecciona uno o varios archivos CSV.

    Máximo recomendado: 100 archivos y 200 MB por lote. Abre el CSV descargado con Excel o tu editor habitual y comprueba las columnas.
