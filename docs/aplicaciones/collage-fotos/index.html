COLLAGE DE FOTOS

Convierte una carpeta de imágenes en una cuadrícula clara para compartir, revisar o archivar.

Tus imágenes se quedan en tu dispositivo. El collage se compone dentro de este navegador y se descarga como una imagen nueva. No hay cuentas, subidas ni cambios en los originales.

Elige las fotos en el orden que quieras verlas. Con «Rellenar celda» la cuadrícula queda uniforme; con «Mostrar completa» no se corta la imagen y se usa el color de fondo.

Descargar collage
Una cuadrícula sirve para revisar o compartir un conjunto de fotos. Para imprimirla, elige un tamaño de celda y una separación que mantengan legibles los detalles y los nombres.
Compatible con JPG, PNG y WebP en navegadores modernos. La aplicación procesa hasta 40 imágenes por collage y genera una única imagen descargable.
