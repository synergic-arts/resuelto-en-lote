CSV A JSON

Convierte una tabla de Excel o una exportación en registros listos para una API o una aplicación.

El archivo se queda en tu dispositivo. La lectura, la transformación y la descarga se realizan dentro de este navegador. No hay cuentas, subidas ni conexiones de red.

Los valores se mantienen como texto para no cambiar códigos como 00123, identificadores largos o referencias con ceros iniciales. Las comas, comillas escapadas y saltos de línea dentro de una celda se respetan.

Pega un CSV o selecciona un archivo.

Una decisión deliberada. Este conversor no adivina tipos: fechas, importes, códigos y teléfonos se exportan como texto para evitar cambios silenciosos. Si una API necesita números o booleanos, conviértelos con el esquema que corresponda.
