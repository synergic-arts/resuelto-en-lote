REDIMENSIONA IMÁGENES

Cambia el tamaño de muchas fotos de una vez, sin instalar nada.

Procesamiento local. Las imágenes se leen y se transforman dentro de tu navegador. No se envían a Internet y los originales no se modifican.

Se conserva la proporción y nunca se amplía una imagen más allá de su tamaño original. Las descargas reciben un nombre nuevo.

Selecciona una o varias imágenes.

    Máximo recomendado: 100 imágenes y 200 MB por lote. Comprueba visualmente las copias nuevas antes de archivar los originales.
