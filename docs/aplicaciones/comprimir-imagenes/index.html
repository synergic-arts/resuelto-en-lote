Aplicación web privada

COMPRIMIR IMÁGENES

Haz que una foto pese menos de 100 KB, 200 KB o el límite que te pida un formulario.

Tus fotos no se suben. El navegador decodifica, comprime y prepara las copias en tu dispositivo. No hay cuenta, servidor ni cambio en los originales.

El compresor busca automáticamente una calidad que quede por debajo del límite y reduce las dimensiones solo si hace falta. Para fotografías usa JPG; para una web, WebP suele ser una buena opción.

Selecciona una o varias imágenes.

Todavía no hay resultados.

    Un límite de peso siempre implica un compromiso. El resultado puede perder algo de detalle y la aplicación puede reducir píxeles si una foto no cabe con una calidad razonable. Comprueba la copia descargada antes de enviarla.
    Compatible con JPG, PNG y WebP en navegadores modernos. La aplicación prepara cada imagen por separado y ofrece una descarga para cada copia.
