    Isto não é OCR. O aplicativo funciona com PDFs que já contêm texto selecionável. Páginas digitalizadas como imagens exigem OCR.
    Compatível com navegadores modernos. Os PDFs originais não são modificados nem enviados a um servidor. Layouts complexos, colunas e tabelas podem exigir revisão do TXT.
