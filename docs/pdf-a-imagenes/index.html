    PNG y JPG sirven para cosas distintas. PNG conserva mejor el texto y los gráficos, pero ocupa más. JPG pesa menos y resulta práctico para enviar una página como imagen, aunque comprime el detalle.
    Compatible con navegadores modernos. El PDF no se modifica: se generan imágenes nuevas. Para mantener una respuesta fluida, se recomienda no superar 100 MB ni usar una escala excesiva en páginas muy grandes.
