Privacidad y seguridad

Aplicaciones web

El navegador lee únicamente los archivos que eliges. El procesamiento se ejecuta en tu equipo y el código impide conexiones de la aplicación a servicios externos. No hay cuentas, formularios de envío, analítica ni cookies.

Seleccionar archivos o una carpeta no concede acceso al resto del equipo. Las aplicaciones web no modifican los originales: muestran resultados o crean archivos nuevos únicamente después de una acción explícita.

La aplicación para unir PDF utiliza una copia local de pdf-lib 1.17.1, con licencia MIT. El procesamiento se ejecuta en un proceso aislado y se detiene si supera el tiempo de seguridad. No admite PDF cifrados y no debe considerarse un desinfectante de documentos.

Aplicaciones de Windows

Las descargas son portables y no necesitan Python. No están firmadas digitalmente, por lo que Windows puede mostrar una advertencia. Descárgalas solo desde el repositorio oficial, compara la huella con SHA256SUMS.txt y prueba primero con copias.

Operaciones que cambian archivos

La aplicación de renombrado genera una vista previa antes de aplicar cambios. La de organización copia las fotos a otra carpeta y conserva los originales. Ninguna aplicación debe sustituir una copia de seguridad.
