# Comparar carpetas

Recorre dos carpetas y compara la huella SHA-256 de cada archivo. El CSV distingue `SOLO_ORIGEN`, `SOLO_DESTINO` y `CAMBIADO`.

La forma más rápida es [abrir la aplicación web](https://synergic-arts.github.io/resuelto-en-lote/aplicaciones/comparar-carpetas/). Los archivos se leen dentro de tu navegador y no se envían a ningún servidor.

También puedes descargar `comparar_carpetas.exe` para Windows y abrirlo con doble clic. Ninguna versión copia, mueve ni elimina archivos. El modo SHA-256 puede tardar con archivos muy grandes.
